## 1. 목표

교회소개·예배안내와 **같은 편집 계약·시각 밀도**로 교육부서 3탭, 선교사역 2탭을 고도화한다.

### 1.1 이번 범위

1. **교육부서** `/education`: 고정 3탭(유초등부 / 중고등부 / 청년대학부). 탭당 풀뷰 패널(사진 + 본문 + 일정).
2. **선교사역** `/missions`: 국내선교 / 국외선교. 탭별 카드 목록 + **추가·삭제·순서**.
3. 관리자 인라인 편집은 `FormField` + `MediaInputField` + Toast. `alert` 금지.

### 1.2 비범위

- 탭별 별도 URL (`/education/youth` 등)
- 교육부서 탭 추가/삭제 (3탭 고정)
- 선교 후원 결제, 기도제목 게시판
- 방문자 댓글

## 2. 교육부서 (`/education`)

| 항목 | 결정 |
|------|------|
| 탭 키 | `elementary` / `youth` / `youngadult` |
| 기본 탭 | 유초등부 |
| 탭 수 | **고정 3**. 원격에 빠진 키는 시드로 채움 |
| 레이아웃 | 교회소개와 동일 계열: `min-h-[calc(100dvh-header)]`, md+ 사진 2 : 글 1 |
| 이미지 | 4:3~16:10, `object-cover`, Storage `uploads/education/` |

### 2.1 필드

| 필드 | 필수 | 설명 |
|------|------|------|
| `deptKey` | 고정 | 탭 식별. 편집 불가 |
| `name` | 예 | 탭·제목 (기본: 유초등부 등) |
| `image` | 예 | 대표 사진. 비우면 기존/시드 유지 |
| `missionText` | 예 | 비전·소개 본문 (`\n` 유지) |
| `scheduleInfo` | 권장 | 모임 일정 한 줄 |
| `targetAge` | 선택 | 대상 (예: 초등 1~6학년) |
| `place` | 선택 | 장소 (예: 유초등부실) |

### 2.2 공개 화면

```
[ PageShell: 교육부서 ]
[ Tabs: 유초등부 | 중고등부 | 청년대학부 ]
[ 사진 2/3 ] [ eyebrow + 부서명 + 대상/장소 칩 + 본문 + 모임 일정 ]
```

## 3. 선교사역 (`/missions`)

| 항목 | 결정 |
|------|------|
| 탭 키 | `domestic` / `overseas` |
| 항목 | 가변 리스트. 탭 안에서만 추가·삭제·순서 |
| 레이아웃 | 사역자 소개와 같은 **카드 그리드** (이미지 + 이름 + 지역 + 설명) |
| 편집 | 예배안내와 같은 **목록 에디터** (드래그 순서, 추가/삭제, 모달 스크롤) |
| 이미지 | 16:10, Storage `uploads/missions/` |

### 3.1 필드

| 필드 | 필수 | 설명 |
|------|------|------|
| `type` | 고정 | `domestic` \| `overseas` (탭에서 결정) |
| `name` | 예 | 사역/선교지 이름 |
| `description` | 권장 | 소개·기도 제목 |
| `region` | 선택 | 지역 (예: 서울 동대문구, 동남아시아) |
| `image` | 선택 | 대표 사진. 없으면 플레이스홀더 |
| `order` | 예 | 탭 내 표시 순서 |

### 3.2 공개 화면

```
[ PageShell: 선교사역 ]
[ Tabs: 국내선교 | 국외선교 ]
[ 카드 그리드 2열(모바일 1열) ]
  이미지 / 지역 / 이름 / 설명
```

빈 목록: 점선 패널 + 안내 문구.

## 4. 편집 UX

- 텍스트: `FormField` (`label` + 한 줄 `hint`)
- 미디어: `MediaInputField` `imageOnly`, 빈 값이면 기존 URL 유지
- 저장: Toast 성공/실패, 「저장 후 게시」
- 교육: 탭당 단일 블록 편집
- 선교: 탭당 목록 일괄 편집 (예배안내와 동일 드래그 패턴)

---

## 5. 인수 기준

1. `/education` 3탭이 URL 변경 없이 전환되고, 시드 또는 Firestore 내용이 보인다.
2. 원격에 부서가 일부만 있어도 3탭이 모두 뜬다 (시드 폴백).
3. `/missions` 2탭이 URL 변경 없이 전환된다.
4. 관리자는 교육 탭 본문·사진·일정·대상·장소를 저장할 수 있다.
5. 관리자는 선교 항목을 추가·삭제·순서 변경·사진 지정할 수 있다.
6. `npm test` · `npm run build` 통과.
7. 모바일 1열 / 데스크톱 그리드가 깨지지 않는다.
