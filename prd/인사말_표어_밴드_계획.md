# 홈 — 인사말 + 연간 표어 밴드 계획

- 작성일: 2026-08-13
- 상태: 구현 대상
- 관련: `PastorGreetingSection`, `AnnualMottoSection`, `GreetingMottoBand`

---

## 1. 목표

- **한 줄 전체 = 인사말만** 템플릿 구조를 제거한다.
- 동일 밴드 안에서 **축소 인사말(Pull-quote)** + **연간 표어(타이포)** 를 비대칭 배치한다.
- **인사말·표어 각각** 관리자 인라인 편집(`EditableBlock`)을 제공한다.
- 표어는 PNG 이미지가 아니라 **타이포 재구성**한다. (`prd/images/2026년표어.png`는 시드 내용 참고용)

---

## 2. 레이아웃

```
┌──────────────────────────────┬─────────────────────────────┐
│  담임목사 인사말 (편집)        │  연간 표어 (편집)             │
│  Pull-quote + 세로 초상       │  타이포: 연도·표어·구절·3실천 │
│  짧은 본문 + 성함             │                             │
└──────────────────────────────┴─────────────────────────────┘
        ~55–58%                          ~42–45%
```

| 뷰포트 | 배치 |
|--------|------|
| `md+` | 2열 그리드 (인사말 좌 / 표어 우) |
| 모바일 | 인사말 → 표어 세로 스택 |

공통: `Reveal` 스크롤 리빌 유지. 인사 사진은 약한 micro-parallax 유지 가능.

---

## 3. 인사말 (데이터·편집)

### 표시
- 라벨: 담임목사 인사말
- Pull-quote: `quote` 필드 우선, 없으면 `message` 첫 문장
- 세로 초상 (3:4 권장)
- 본문, 서명 `— {pastorName}`

### Firestore `pastorGreeting/main`
| 필드 | 설명 |
|------|------|
| pastorName | 성함 |
| photoUrl | 사진 |
| message | 본문 |
| quote | 인용구 (선택) |
| updatedAt | |

### 편집 필드
FormField: 성함, 인용구, 본문 / MediaInputField: 사진(imageOnly, folder=`pastor`)

---

## 4. 표어 (데이터·편집)

### 표시 (타이포)
```
{year}년도 표어
{motto}
{scripture}

1. {practices[0]}
2. {practices[1]}
3. {practices[2]}
```

- `year` 비어 있으면 `new Date().getFullYear()`

### Firestore `annualMotto/main`
| 필드 | 설명 |
|------|------|
| year | 선택. 없으면 현재 연도 |
| motto | 표어 본문 |
| scripture | 성경 구절 |
| practices | string[3] |
| updatedAt | |

### 시드 (2026년표어.png 기준)
- motto: 옛 사람을 벗고 새사람을 입자!
- scripture: 에베소서 4:22-24
- practices: 생각을 기도처럼! / 언행을 말씀처럼! / 이웃을 주님처럼!

### 편집
FormField: 연도, 표어, 구절, 실천 1~3
